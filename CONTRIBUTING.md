# Contribuer à PHARE

PHARE est réparti entre plusieurs dépôts parce que le robot lui-même est composé de plusieurs briques. Il n'est pas nécessaire de connaître toute l'organisation avant de commencer.

## Où travailler ?

- **La solution est encore à explorer :** créer un [PHARE Lab](https://github.com/phare-ensta/phare-lab-template/issues/new?template=create-lab.yml).
- **Le travail doit être intégré au robot :** utiliser le guide [Où placer le code et les artefacts PHARE](https://github.com/phare-ensta/phare-docs/blob/main/docs/getting-started/repository-routing.md).
- **Un doute subsiste :** demander avant de déplacer ou dupliquer du code entre dépôts.

## Git

Pour une contribution normale :

1. travailler sur une branche ;
2. faire des commits lisibles ;
3. ouvrir une pull request expliquant brièvement ce qui change ;
4. indiquer comment la modification a été vérifiée lorsque c'est pertinent.

Les dépôts spécialisés peuvent ajouter leurs propres règles lorsqu'elles sont réellement nécessaires, notamment pour le matériel, la sécurité, les données ou la CI.
