# Gouvernance GitHub de PHARE

Ce dépôt contient les éléments communs à l'organisation GitHub PHARE-ENSTA : profil public, règles de contribution, politique de sécurité, modèles de pull request et, à terme, workflows réutilisables.

Il ne contient aucun code produit ni état opérationnel du robot.

La langue de travail et de documentation du projet est le français. Les noms d'API, symboles de code et termes techniques établis peuvent rester en anglais lorsqu'ils constituent le vocabulaire naturel de l'écosystème utilisé.
