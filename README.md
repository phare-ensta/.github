# .github

Configuration GitHub publique de l'organisation PHARE-ENSTA.

- `profile/README.md` présente PHARE et les dépôts stables de l'organisation ;
- `CONTRIBUTING.md` donne le chemin de contribution le plus simple ;
- les réglages et modèles communs aux dépôts privés sont maintenus dans [`.github-private`](https://github.com/phare-ensta/.github-private).
