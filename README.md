# Gouvernance GitHub de PHARE

Ce dépôt contient les éléments communs à l'organisation GitHub PHARE-ENSTA : profil de l'organisation, règles de contribution, politique de sécurité, modèles de pull request et, à terme, workflows réutilisables.

Il ne contient aucun code produit ni état opérationnel du robot.

## Langues et conventions de nommage

La documentation, les explications techniques, les descriptions de dépôts et le contenu rédactionnel du projet sont rédigés en français.

Les éléments de traçabilité Git restent en anglais afin de conserver une convention homogène avec l'écosystème logiciel :

- messages de commit en anglais, au format Conventional Commits ;
- titres de pull request en anglais, de préférence au même format ;
- titres d'issues en anglais ;
- noms de branches en anglais, courts et explicites.

Les noms d'API, symboles de code et termes techniques établis restent en anglais lorsqu'ils suivent les conventions de l'écosystème utilisé.
